# Plan Feature

Before coding:
1. restate the requested feature;
2. identify product requirements;
3. identify affected architecture layers;
4. identify reusable components;
5. identify data-model changes;
6. identify edge cases;
7. identify tests;
8. identify platform-specific work;
9. identify documentation changes.

Produce a concise implementation plan.

Do not code until the plan is internally coherent.
