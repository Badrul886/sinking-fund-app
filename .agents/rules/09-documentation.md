# Documentation & Handoff

Documentation is part of implementation.

After meaningful changes:
- update `docs/CURRENT_STATE.md`;
- update `docs/CHANGELOG.md`;
- update `docs/DECISIONS.md` for meaningful decisions;
- update architecture/design docs when behavior changes.

Record:
- what changed;
- what was verified;
- what remains;
- known issues;
- exact next step.

The goal is that a completely new Antigravity chat can continue the project without needing the previous conversation.
