# Design System

## Status
`FOUNDATION — implementation begins in Phase 2`

## Product personality
- Calm
- Optimistic
- Tactile
- Intelligent
- Trustworthy
- Slightly playful
- Premium

## Avoid
- generic fintech dashboards
- spreadsheet aesthetics
- arbitrary gradients
- inconsistent icon families
- placeholder illustrations
- meaningless animation
- excessive visual noise
- childish gamification

## Tokens
Centralize:
- color
- typography
- spacing
- radius
- elevation
- borders
- opacity
- icon sizes
- touch targets
- motion
- illustration treatment

## Component rule
Before creating a component, search for an existing component with the same responsibility.

## Accessibility
Design must support:
- VoiceOver
- TalkBack
- Dynamic Type / font scaling
- sufficient contrast
- semantic labels
- minimum touch targets
- reduced motion
- color-independent status communication
