# Polish UI

Perform a visual-quality pass without changing product scope.

Inspect:
- spacing;
- hierarchy;
- typography;
- icon consistency;
- component consistency;
- animation timing;
- transitions;
- touch targets;
- accessibility;
- empty/loading/error/success states;
- keyboard behavior.

Remove generic/template-like visual decisions.

Do not add decorative complexity that does not improve the product experience.
