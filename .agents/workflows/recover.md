# Recover Project Context

Use this workflow after opening a new Antigravity chat or when context appears incomplete.

Read:
1. `docs/MASTER_PRODUCT_SPEC.md`
2. `docs/CURRENT_STATE.md`
3. `docs/ARCHITECTURE.md`
4. `docs/DECISIONS.md`
5. `docs/KNOWN_ISSUES.md`
6. relevant source files
7. recent Git history

Then reconstruct:
- current phase;
- implemented features;
- active task;
- unfinished work;
- known issues;
- tests;
- next safe action.

Do not recreate functionality that already exists.
