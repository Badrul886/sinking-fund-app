# Design System Governance

## Always On

Use `docs/DESIGN_SYSTEM.md` as the design authority.

Before creating UI:
1. search existing components;
2. reuse existing tokens;
3. reuse existing interaction patterns;
4. only create a new component when responsibility is genuinely new.

The UI must not look like a generic AI-generated fintech template.

Do not introduce:
- arbitrary colors;
- arbitrary spacing;
- mixed icon styles;
- unexplained gradients;
- meaningless animation;
- placeholder art in final UI.

Every visual state should have an intentional reason.
