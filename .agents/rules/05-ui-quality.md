# UI Quality Standard

A feature is not complete because it compiles.

Review:
- hierarchy;
- spacing;
- typography;
- iconography;
- loading;
- empty;
- success;
- error;
- offline;
- accessibility;
- motion;
- haptics where relevant;
- keyboard/input behavior;
- platform conventions.

Animations must communicate state, feedback, spatial continuity, reward, or reduce perceived waiting.

Do not add animation merely for decoration.
